DJANGO · PYTHONurls.py
# urls.py
from django.urls import path
from . import views

urlpatterns = [
    path(
        "products/",
        views.product_list,
        name="products",
    ),
]

URLconf łączy wzorzec ścieżki z funkcją view.

LARAVEL · PHProutes/web.php
use Illuminate\Support\Facades\Route;
use App\Http\Controllers\ProductController;

Route::get(
    "/products",
    [ProductController::class, "index"]
);

Route dopasowuje metodę HTTP i ścieżkę do akcji kontrolera.

KOD · POBIERANIE DANYCH

Query po aktywne produkty

Oba ORM-y pozwalają opisać intencję w kodzie zamiast ręcznie składać SQL.

DJANGO · VIEWviews.py
from django.shortcuts import render
from .models import Product

def product_list(request):
    products = (
        Product.objects
        .filter(is_active=True)
        .order_by("name")
    )
    return render(
        request, "products/index.html",
        {"products": products}
    )

QuerySet jest leniwy; dane trafiają do template jako kontekst.

LARAVEL · CONTROLLERProductController.php
use App\Models\Product;

public function index()
{
    $products = Product::query()
        ->where("is_active", true)
        ->orderBy("name")
        ->get();

    return view(
        "products.index",
        ["products" => $products]
    );
}

Eloquent buduje zapytanie dla modelu i przekazuje kolekcję do widoku.

W przykładach zakładamy istniejący model Product z polem is_active i nazwą produktu.

ZALETY I OGRANICZENIA

Co zyskujemy, co trzeba rozważyć?

D
PYTHON · MVT

Django

+

Spójny zestaw funkcji w core; mniej decyzji integracyjnych na starcie.

+

Admin, ORM i migracje pomagają szybko uruchomić zaplecze danych.

−

Rozbudowany zestaw może być większy niż potrzeby małej usługi.

−

Warto poznać konwencje MVT i podział na aplikacje Django.

L
PHP · MVC

Laravel

+

Konwencje, Artisan i spójne API upraszczają typowy workflow PHP.

+

Szeroki ekosystem pomaga dobrać narzędzia do rosnącej aplikacji.

−

−

Panel administracyjny wymaga osobnego narzędzia lub własnej implementacji.

To kompromisy zależne od projektu i zespołu — nie uniwersalny ranking.
